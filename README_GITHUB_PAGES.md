# ColorCraft — GitHub Pages Ready

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload/commit the contents of this project to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Push to `main` or manually run **Deploy ColorCraft to GitHub Pages** from the Actions tab.
6. Wait for the workflow to finish. GitHub will provide the live URL.

The workflow runs `npm ci`, builds the Vite app, and publishes the generated `dist` folder.

Do not open `index.html` directly from the source folder. GitHub Pages serves the production build generated by Vite.
